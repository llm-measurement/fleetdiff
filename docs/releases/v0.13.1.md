# fleetdiff v0.13.1

Two Langfuse report fixes:

- Clean exports with valid DEFAULT, DEBUG or WARNING observation levels no
  longer flag every record for usage review just because provider request
  status is unknown (#81). ERROR observations remain visible; missing or
  invalid levels still require review. Observation severity is separate from
  provider request status and billing finality, which remain unknown.
- With `--group-by provided_model_name`, the model section, token contributors
  and cache rankings use the same model labels. Exact bundled public model
  IDs remain visible; private names remain aliased. Keyed identities and
  project separation are unchanged.

Token and cost totals are unchanged. No new dependencies.
