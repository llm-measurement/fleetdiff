# v0.6.1 Release Notes

This patch brings llm-sketchkit v0.2.3 hardening to fleetdiff's summary readers:
parser allocation limits, more efficient summary combination, and safer
secret and error diagnostics.

## Compatibility

Existing identities, summary wire formats and accounting remain unchanged.
The build keeps `golang.org/x/text` v0.41.0. This is the identity-preserving
sketchkit backport, not its v0.3.0 migration. Readers reject oversized or malformed
encodings according to sketchkit's
[resource limits](https://github.com/llm-measurement/llm-sketchkit/blob/v0.2.3/docs/OPERATIONS.md).

The LiteLLM spend importer and the summary, trace and configuration commands
keep their v0.6.0 behavior. Replace the verified executable; no collector
upgrade, key rotation or window reset is required.

## Install And Verify

Use the [verified installer](../OPERATIONS.md#install-and-verify) with
`v0.6.1`, or verify the release archives before extracting them. Linux and macOS
archives cover AMD64 and ARM64, built with Go 1.26.9, with dependency licenses,
checksums, an SBOM and signed build provenance.

The release workflow tests the packaged commands on all four platforms and
exercises the pinned LiteLLM SQL export through the packaged importer. The
installer's default is now v0.6.1. Release automation and the synthetic capture
recipe also include the reviewed dependency updates merged since v0.6.0.
