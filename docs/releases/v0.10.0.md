# v0.10.0 Release Notes

**USD 0.154400 -> 0.109398 to 0.147974 under workload assumptions.** Move half
the covered Sonnet traffic to Sol in the checked example and compare the cost
using measured QA, extraction and coding factors. The new `what-if` command
re-prices recorded usage locally, with dated prices and coverage beside the result.

## Try A Model Mix

Use a request-level LiteLLM export with input, output, cache-read and cache-write
columns. Select a completed UTC period and the share of traffic to move:

```sh
fleetdiff what-if --litellm-spend spend.csv --period 2026-10-07 \
  --from claude-sonnet-5-5 --to gpt-6.1-sol --fraction 0.5
```

The [synthetic example](../WHAT_IF.md#no-data-handy-try-the-sample) produces:

```text
Moving 50% of claude-sonnet-5-5 traffic to gpt-6.1-sol (covered usage): $0.154400 -> $0.109398 to $0.147974, depending on workload assumptions.
```

Level 1 keeps output verbosity unchanged and reports USD 0.148703. Level 2
applies each measured workload's output factor. Three observations are priced;
one with missing component details is excluded rather than treated as free.

Use a scenario file for multiple moves, key/team scopes to select traffic,
and a workload map to assign QA, extraction or coding. Moves apply to the
original traffic without cascading. `--prices` supplies dated rate overrides;
`--format json` exposes the same costs, provenance and exclusions for automation.
See the [what-if guide](../WHAT_IF.md) for file formats and arithmetic.

## Per-Model Summary Input

`what-if --summaries` now reads the optional `model_usage` v1 block. Supply
`--expected` producers and the producer's `--model-usage-contract` identifier.
Only complete per-model cohorts are priced; invalid, missing and origin-unknown
usage remain exclusions. Cumulative snapshots replace earlier snapshots, and
replayed files do not double totals. Input histograms retain per-request extrema
so a large aggregate is not mistaken for one request or averaged across a price
tier. Key/team scopes still require request-level exports.

Upgrade readers before opting a producer into the new format. Legacy summaries
and existing commands retain their behavior; enabled blocks are rejected by
older readers. The reader uses sketchkit's v0.2.4 maintenance backport to preserve
its existing identity normalization. See the [version matrix](../WHAT_IF.md#collector-summaries).

## Evidence

The [public numeric bundle](../../evidence/model-mix/README.md) contains 468
fit observations from 117 tasks on four requested model IDs, source/license
pins, original estimates and 56 prediction-audit summaries. Factors are geometric
means of paired token ratios; their mean intervals reproduce offline:

```sh
python3 -B scripts/reproduce-model-mix.py --check
python3 -B -m unittest discover -s evidence/model-mix -p 'test_*.py'
```

## Limits

These are descriptive scenarios, not forecasts or invoices, and no quality
equivalence is claimed. The original per-request prediction test passed coverage
and width together in 0/12 workload-specific and 0/12 pooled comparisons. The
new pooled input factor has no held-out validation; combined mean endpoints
and workload envelopes are not prediction intervals. Customer workloads and
cache behavior can differ. Missing splits or unknown scoped eligibility are
excluded; collector summaries without per-model components report null costs.
