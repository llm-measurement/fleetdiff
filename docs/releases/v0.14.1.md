# fleetdiff v0.14.1

This maintenance release builds fleetdiff with Go 1.26.11 for
[GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859) in the standard library.

It includes the reviewed pgx v5.12.0 update, which contains upstream fixes for
[GHSA-j38q-h3ph-jjpq](https://github.com/jackc/pgx/security/advisories/GHSA-j38q-h3ph-jjpq)
and [GHSA-95fj-3fxw-g62g](https://github.com/jackc/pgx/security/advisories/GHSA-95fj-3fxw-g62g).
This release does not change commands, output formats, or accounting.
