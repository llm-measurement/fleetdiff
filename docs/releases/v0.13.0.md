# fleetdiff v0.13.0

**fleetdiff now reads Langfuse.** Point `fleetdiff investigate --langfuse-export DIR`
at a completed local Langfuse blob-storage export. It reports three things:
- what changed in recorded tokens and cost between two periods;
- which users, sessions, models or prompts contributed to the change;
- how complete the supplied local export is.

It works on local files only. It calls no Langfuse service and no model provider.

## Langfuse exports

- **Formats:** completed `observations_v2` exports in JSON, JSONL or CSV, plain or
  gzip. Each completion manifest's file sizes and row counts are verified.
- **What is compared:** GENERATION observations. Other observation types are
  counted, not mixed in.
- **Grouping:** by user, session, model, environment, release, trace, prompt
  name, or a tag you name. Private labels appear as keyed local aliases by
  default. Observation payload values are never printed.
- **Token detail:** present disjoint cache-read, cache-write and reasoning
  components are added to base input and output without double-counting.
- **Coverage:** missing, rejected, extra and uncovered files and periods are
  reported. A partial copy still shows its observed totals, labeled as partial.
- **Duplicates:** project-scoped observation IDs are deduplicated when their
  accounting and grouping fields match; conflicting copies are refused.
- **Large exports:** bounded readers refuse over-limit files and suggest an
  hourly export schedule. See the [limits](../LANGFUSE.md#limits).

## Provider request counts, for LiteLLM investigations

- **Optional.** Compare LiteLLM's logged requests with local provider daily
  aggregate counts, per model, using provider-qualified IDs or an explicit
  model map. Complete UTC-day differences remain separate from recorded spend.
- **One primary request counter.** Comparisons distinguish declared population
  and counting-unit matches, incomplete pagination, and days that had not
  settled when the counts were retrieved.

## What the numbers mean

- Costs are what Langfuse or LiteLLM recorded, not an invoice. Missing usage is
  counted as missing, never as zero.
- A change between periods shows what moved, not why.
- Provider comparisons are aggregate counts. With matching population and
  counting units they can show a net row deficit, not which requests are
  missing. Without those matches the difference is arithmetic only.
